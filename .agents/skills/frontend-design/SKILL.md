# Frontend Design Guidelines

Guidelines for creating sophisticated, premium interfaces that move beyond generic AI-generated styles.

## 1. Aesthetic Excellence
- **Beyond Generic**: Avoid default shades of blue, red, and green. Use curated, harmonious palettes (e.g., HSL tailored colors, deep textures).
- **Depth and Layering**: Use subtle micro-animations, glassmorphism (where appropriate), and sophisticated shadows to create a sense of premium quality.
- **Typography Matters**: Move beyond system defaults. Use modern, expressive typography that fits the brand's personality.

## 2. Creative Choices
- **Micro-interactions**: Implement subtle feedback for user actions (hover scales, gentle fades, smooth transitions).
- **Layout Sophistication**: Use asymmetrical grids or intentional whitespace to create interest and guide the eye.
- **Originality**: Every choice should feel intentional, not just the result of a generic generator.

## 3. Responsive Integrity
- **Fluid Design**: Interfaces should feel natural across all breakpoints, not just "shrunken" versions of desktop designs.
- **Mobile-First Thinking**: Prioritize ergonomics and clarity on small screens.

## 4. Technical Quality
- **Clean Implementation**: The underlying code should be as beautiful as the UI. Use consistent naming, semantic HTML, and lean CSS/Styled Components.
- **Performance**: High fidelity should not mean high latency. Optimize images, animations, and font loading.
