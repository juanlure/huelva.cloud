# SEO/GEO Optimization Skill

A framework for optimizing web content for both traditional search engines (Google, Bing) and AI search engines (ChatGPT, Claude, Perplexity, Gemini).

## 1. Local Search Optimization (SEO)
- **Local Keywords**: Research and integrate keywords specific to Huelva (city, neighborhoods, province).
- **Schema Markup**: Use `JSON-LD` to define `Article`, `LocalBusiness`, and `Organization`.
- **Meta Tags**: Ensure every page has unique, compelling `<title>` and `description` tags that include local keywords.
- **Image Optimization**: Use descriptive alt text and local filenames (e.g., `choco-frito-huelva.webp`).

## 2. Generative Engine Optimization (GEO)
- **Direct Answers**: Use an "answer-first" structure. Provide concise, factual answers at the top of sections.
- **Statistics & Citations**: Include verifiable data and cite authoritative local sources.
- **FAQ Schema**: Add `FAQPage` schema to typical question-answer content to boost visibility in AI Overviews.
- **Clarity & Fluency**: Avoid jargon. Use clear, fluent Spanish that reflects the local culture.

## 3. Workflow & Verification
1. **Audit**: Regularly check `robots.txt` to ensure AI bots (Googlebot, Bingbot, PerplexityBot, GPTBot, ClaudeBot) have access.
2. **Keyword Research**: Focus on intent-based queries ("donde comer en huelva" vs "restaurantes huelva").
3. **Structure**: Maintain a clear `H1 > H2 > H3` hierarchy and use bullet points/tables for easy data extraction by AI.
4. **Validation**: Use Google's Rich Results Test and Schema.org Validator to ensure markup is correct.

## 4. Key AI Bots to Allow
- `Googlebot` (Google / SGE)
- `Bingbot` (Bing / Copilot)
- `PerplexityBot` (Perplexity)
- `ChatGPT-User` (ChatGPT Browsing)
- `ClaudeBot` / `anthropic-ai` (Claude)
- `GPTBot` (OpenAI API / Search)
